# Illustrated Learning

Скилл для Codex: превращает лекции, документацию, книги и репозитории в понятные учебные объяснения, иллюстрированные HTML-главы и практикумы.

Он задаёт способ работы с материалом: объяснить термины, развить пример, показать механизм, подобрать полезную визуализацию и провести читателя через практическую задачу. Включает редактуру русского текста с сохранением смысла.

## Как использовать

Прикрепите материалы или укажите доступные файлы и ссылки. В начале запроса напишите `$illustrated-learning`, затем задайте тему, свой уровень и желаемый результат.

### Готовая HTML-глава

```text
Используй $illustrated-learning.
По приложенной лекции создай самостоятельную учебную HTML-главу.
Я знаю Python и основы машинного обучения, но впервые изучаю ONNX.
Объясни новые термины, развивай один пример и добавь схемы там,
где они помогут понять вычисления. Включи пошаговую практику
и развёрнутые вопросы с ответами. Сохрани готовые файлы локально.
```

### Сначала объяснение для согласования

```text
Используй $illustrated-learning.
Подготовь текст одной главы по приложенным материалам и опиши
сцены для будущих иллюстраций. Сначала хочу оценить глубину
объяснения; HTML пока не создавай.
```

### Практикум по документации или репозиторию

```text
Используй $illustrated-learning.
По этой документации подготовь практикум: [ссылка].
Моя задача: [конкретный результат]. Работаю в [среда].
Объясни необходимые понятия и проведи по шагам:
что сделать, зачем, какой результат увидеть и как продолжить.
```

### Переработка существующей страницы

```text
Используй $illustrated-learning.
Переработай приложенную HTML-главу: объясни новые термины,
восстанови пропущенные шаги рассуждения, убери пустые подводки
и предложи содержательные иллюстрации. Сохрани удачные части
и согласованный объём.
```

Для знакомого формата можно сразу просить готовую страницу. При новой теме или незнакомом стиле полезно сначала согласовать одну главу с визуальным сценарием, затем расширять материал.

## Установка в Codex

Если скилл уже виден в списке навыков Codex, повторная установка не нужна.

На другом компьютере передайте Codex ссылку на этот репозиторий и попросите:

```text
Используй $skill-installer. Установи скилл из этого репозитория,
из папки skills/illustrated-learning.
```

Для приватного репозитория потребуется доступ к нему. Если установленный скилл не появился, перезапустите Codex и откройте новый чат.

При ручной установке копируйте всю папку `skills/illustrated-learning` в каталог пользовательских скиллов своей установки Codex. В существующей конфигурации автора используется `~/.codex/skills/illustrated-learning`. Перед заменой уже установленной версии сохраните собственные изменения.

Публикация обновления в GitHub сама по себе не обновляет локальную копию. Попросите Codex сравнить версии и обновить установленный скилл.

Прямой вызов через `$имя-навыка` описан в [официальной документации OpenAI](https://developers.openai.com/blog/eval-skills).

## Что входит

- [SKILL.md](skills/illustrated-learning/SKILL.md) — основной процесс и выбор результата.
- [Teaching patterns](skills/illustrated-learning/references/teaching-patterns.md) — примеры объяснений, работа с кодом, формулами и вопросами.
- [Практические инструкции](skills/illustrated-learning/references/practical-guide.md) — маршрут от задачи до проверяемого результата.
- [Визуализации и инструменты](skills/illustrated-learning/references/visuals-and-tools.md) — выбор схем, интерактивов и средств реализации, включая Archify.
- [Редактура](skills/illustrated-learning/references/editorial-style.md) — естественная учебная проза и проверка сохранности смысла.
- [Пример HTML-главы](skills/illustrated-learning/references/onnx-illustrated.html) — ориентир глубины объяснения, который открывают по необходимости. Его композиция и палитра не обязательны для новых глав.

Скилл состоит из инструкций и справочных материалов. Доступность чтения PDF/PPTX, генерации изображений, браузера и других инструментов зависит от среды агента. Archify и Humanizer-RU автоматически не устанавливаются. Исходные лекции и книги в репозиторий не включены.

## Источники подхода

Объясняющие визуализации: [MLU-Explain](https://mlu-explain.github.io/).
Возможный инструмент для архитектурных схем: [Archify](https://github.com/tt-a1i/archify).
Принципы локальной редактуры и сохранения смысла: [Humanizer-RU](https://github.com/ilyautov/humanizer-ru).
Подробные ссылки и границы применения находятся в соответствующих справочных файлах.
